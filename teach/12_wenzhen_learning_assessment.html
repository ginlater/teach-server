阶段一：理解为什么问这12个问题
2天
▼
核心认知：问诊不是走流程，每个问题背后都有皮肤判断逻辑——只有理解了"为什么问"，才能根据顾客情况灵活调整，而不是机械套用

需要理解的3大底层逻辑

逻辑①：问题是皮肤的"因"

皮肤问题是结果，生活习惯/基因/压力是原因，问诊是在找"因"，这样分析才有说服力

逻辑②：问题有时间性

同一个皮肤问题，存在3个月 vs 存在5年，改善难度和方案设计完全不同，时间线很重要

逻辑③：问题有节奏感

问诊要像聊天而不是审讯，每个问题之间需要共情缓冲，不能像填表一样一问到底

学习任务

  • 阅读12个问题各自的"问这个问题的目的"（见第二页全脚本）
  • 能用自己的话说出每个问题和皮肤分析的关联
  • 理解4个问诊阶段的节奏切换时机

3天
▼
背诵目标：不是一字不差地背，而是"背了以后可以说得很自然"——背诵是为了让大脑有足够的素材，遇到真实顾客时可以灵活组合

背诵优先级（按重要性排序）

优先级问题编号原因达标标准
必背Q1 / Q2 / Q12开场引入和期望锁定，直接影响顾客开放程度和成交30秒内流畅说出，语气自然
必背Q7（饮食便秘）/ Q9（压力）最难开口的两个问题，需要特别练习表达方式说完顾客不尴尬，能接续追问
重要Q3 / Q4 / Q8触发事件/护肤习惯/睡眠——问诊核心信息来源能用2-3种不同方式问同一件事
重要Q5 / Q6 / Q10 / Q11反复频次/遗传/防晒/医美史——补充判断维度根据顾客情况选择性问，不生硬
背诵方法推荐：第1天默读理解→第2天对镜子大声说→第3天对同事说→第4天录音回听，找"读书感"并改掉

阶段三：活学活用——根据顾客反应调整节奏
4天
▼

顾客类型不同，问诊策略要跟着调整。学会识别3种顾客类型并切换节奏：

话多型顾客

主动倾诉，信息量大

  • 顺着她说，不要打断
  • 适时总结归纳，把重点带回来
  • 少问多听，及时做记录
  • 控制总时长，不超12分钟

沉默型顾客

回答简短，不主动展开

  • 用二选一问题代替开放式
  • 先说顾问自己的观察，再问她
  • 给她"对"的机会，让她点头
  • 不沉默对视，要用语言填充

防御型顾客

警惕心强，觉得"你要卖我东西"

  • 先降低商业感，说"不一定要买"
  • 问题从生活聊天切入，不从皮肤
  • 强调问诊目的是"帮你少花冤枉钱"
  • 慢热，先建立关系再深入问诊

12问诊完整脚本——每题标准问法 × 追问 × 目的
学习重点：问法要口语化，追问要有逻辑感，目的要记在心里
Q1
开场引入
让顾客开口，确认主诉
标准问法
"今天来，最让您不舒服或最在意的皮肤问题是什么？随便说，没有标准答案。"
过渡语 / 追问
"嗯，您说的这个我记下来了，等会儿我们检测图出来重点看这里。除了这个，还有没有其他小烦恼？比如有时候会有，但平时不太在意的？"
✦ 为什么这么问：先让顾客说主诉，让她感受到被重视，然后追问"其他的"是为了发现顾客自己没意识到的潜在问题，这些往往是后续加单的切入点
Q2
问题聚焦
判断急慢性，评估改善难度
标准问法
"您说的这个情况，大概是从什么时候开始明显起来的？是突然出现的，还是慢慢越来越明显的？"
过渡语 / 追问
"那段时间生活上有什么变化吗？我问这个是因为皮肤问题通常和某个生活事件是有关联的，找到那个时间点，分析起来更准确。"（自然衔接Q3）
✦ 为什么这么问：时间越长的问题改善越慢，这是预期管理的关键信息；"突然出现"往往有明确触发事件，"慢慢变严重"多是累积性因素
Q3
问题聚焦
找触发事件，定位成因
标准问法
"在这个情况出现之前，您的生活有没有什么变化？比如——换了护肤品、换了城市或环境、工作压力突然变大、生完孩子、或者经历了什么比较大的事情？"
过渡语 / 追问
"您觉得和那个有关吗？还是说那之前皮肤就有一点苗头了？"
✦ 为什么这么问：触发事件是最强的成因证据，找到了就能对症下药；列举几个选项（换品/换城市/生孩子）是帮助顾客回忆，不是让她乱猜
Q4
问题聚焦
排查护肤误区，了解现有习惯
标准问法
"您现在在家是怎么护肤的？早上和晚上各大概做哪些步骤，用什么东西，您随便说说，不用很精确。"
过渡语 / 追问
"用这些产品大概多久了？换新品之后皮肤有没有什么反应？
洁面的时候，您用热水还是温水？洗多久？有没有用洗脸仪？"
✦ 为什么这么问：很多顾客的皮肤问题源自护肤步骤错误（如过度清洁/成分冲突），这里是排雷区；找到误区后，分析时可以给顾客"恍然大悟"的体验，大幅提升专业信任感
Q5
问题聚焦
区分内因/外因，判断规律性
标准问法
"您说的这个问题，是一直持续都有，还是某些时候会特别明显？比如生理期前后、换季的时候、熬夜后、或者吃了什么之后特别厉害？"
过渡语 / 追问
"每次发的时候，大概多久会好转？是自己好，还是用了什么东西才好？"
✦ 为什么这么问：周期性发作多与内分泌相关（生理期/压力）；外因触发多与接触刺激有关；规律找到了，方案就更精准
Q6
关联扩展
评估先天遗传因素
标准问法
"您妈妈或者家里长辈，皮肤是什么类型的？有没有类似的情况——比如也容易敏感、容易长斑、或者毛孔也比较明显？"
过渡语 / 追问
"如果有类似的话，先天因素就占了一部分，这个不用担心，只是说明我们要更早介入做预防，不能光靠护肤品。"
✦ 为什么这么问：遗传因素影响色斑/痘痘/敏感的改善速度和顶峰状态，提前和顾客沟通，做好预期管理；也可以顺势说明"为什么这么多年一直没彻底好"
Q7
饮食习惯 ⚠️ 难题
关联内分泌/代谢/肠道
标准问法
"平时饮食上——喜欢吃辣吗？甜食呢？油炸或者奶制品呢？大概是经常吃还是偶尔？"
过渡语 / 追问（关键！）
"饮食对皮肤影响真的挺大的——顺便问一下，最近排便情况还好吗？是比较规律，还是有时候便秘？"
（语气要轻松随意，放在饮食问题之后顺带带出，不要单独强调）
⚠️ 最容易说错的地方：不要直接问"您便秘吗？"——这会让顾客觉得很唐突。要放在饮食话题里顺带问，用"顺便"引出，语气要像聊天而不是问诊。练习要点：这句话说完后，用微笑保持眼神接触，让顾客觉得这很正常。
Q8
关联扩展
关联皮肤修复力和代谢
标准问法
"您平时大概几点睡觉？睡眠质量怎么样——入睡容不容易？睡着以后会不会中途醒？"
过渡语 / 追问
"熬夜的话是工作原因还是习惯性睡不着？因为这两个对皮肤的影响方向不太一样。
您有没有发现——熬夜之后第二天皮肤特别容易出状况？"
✦ 最后一句追问是引导顾客自己说出"是的，熬夜影响皮肤"——这样她在分析环节听到"熬夜是原因之一"时，会更容易接受
Q9
关联扩展
关联皮质醇/激素/皮脂分泌
标准问法
"工作上最近压力大不大？或者生活里有没有什么比较烦心的事情，会让您老是在想、睡前停不下来那种？"
过渡语 / 追问
"精神压力对皮肤的影响其实挺直接的——压力一大，体内皮质醇就高，皮脂腺会更活跃，皮肤就容易出问题。您有没有感觉到，最近压力大的时候皮肤会特别容易出状况？"
✦ 稍微解释"为什么问这个"，让顾客觉得这个问题专业且有依据，不是无关的闲聊
Q10
关联扩展
评估光老化风险和防晒习惯
标准问法
"平时出门有涂防晒的习惯吗？开车或者坐靠窗的位置，有在意防晒吗？"
过渡语 / 追问
"是室内工作为主，还是经常外勤？
用的是什么防晒——物理的还是化学的？SPF多少？一般几个小时补涂一次？"
✦ "开车/靠窗"这个细节很多顾客没意识到，说出来会让顾客有"原来还有这个！"的感觉，瞬间提升专业感，后续分析UV图时可以对应说明
Q11
关联扩展
排查禁忌，找医美关联
标准问法
"之前有做过医美项目吗？比如激光、水光、填充、或者手术这些？"
"皮肤或者食物上有过敏的情况吗？"
过渡语 / 追问
"方便说一下大概什么项目、什么时候做的吗？我问这个是因为设计今天方案的时候要考虑进去，避免和之前的项目冲突，或者可以借力配合。"
✦ 说明"为什么问医美史"很重要，否则顾客会以为你在打探隐私；"借力配合"这个说法比"避免冲突"更正向，顾客更容易接受
Q12
期望锁定 🎯 成交关键
对齐需求，锁定成交锚点
标准问法
"说了这么多——如果让您选一个最希望改善的地方，或者说三个月以后照镜子，最希望看到什么样的变化，您会选什么？"
过渡语（结束问诊，引入分析）
"好，我知道了。您今天告诉我的这些信息非常有价值，等会儿检测图出来，我会重点针对您说的这几个问题来给您分析，我们来看看皮肤里面到底发生了什么。"
🎯 这句话顾客说出来，就是你的成交锚点。后续报价时一定要引用："您之前说最希望改善XX，我们这个方案就是专门针对这个来设计的……"
过渡语精讲——让12个问题听起来像"一段流畅的对话"
没有过渡语，问诊变成审讯；有了过渡语，问诊变成聊天。这是新老顾问最明显的差距所在
核
过渡语的3个作用
先理解
▼

作用①：承接

把上一个问题的回答和下一个问题自然衔接，避免"好，下一个……"的割裂感

作用②：共情

顾客说完之后先有回应，让她感受到"你在认真听"，而不是等她说完就接着问

作用③：解释

告诉顾客"为什么问这个"，让问题显得专业而不是无关紧要的闲聊

过渡语5大句式模板（全部背熟）
必背
▼
句式类型模板使用时机
共情承接型 "嗯，明白了——[复述顾客的话]，这个很重要，我等会儿分析会重点说这里。" 顾客说完主诉后，过渡到追问
解释铺垫型 "我再问您一个，这个问题听起来和皮肤没什么关系，但其实影响挺大的——" 问饮食/便秘/压力等敏感问题前
关联引导型 "您刚说的[某个细节]，这个和您皮肤的[某个问题]其实是有关联的，我们等会儿检测图里可以验证……" 发现问诊信息和皮肤有关联时
选择辅助型 "您觉得主要是[选项A]这种情况，还是更像[选项B]？" 顾客不知道怎么回答时，给她选项
总结收束型 "好的，我基本了解了。您今天最主要的是[总结]，成因可能和[归因]有关——我们来看看检测图。" 问诊结束，过渡到图谱分析

"生完孩子之后——这个很关键！产后激素变化对色斑的影响非常大，很多人的斑就是从这个时候开始的。那当时有没有做什么护理，还是说一直就没有专门处理过？"

✦ 注意：每次顾客回答完，顾问都先有"回应"再"提问"，绝不是"好，下一个问题"这种割裂感

#错误表现危害正确做法
1问完一个问题立刻问下一个，没有过渡顾客感觉被审讯，关闭心理防线每题后先共情回应，再提下一个问题
2顾客还在说，顾问插话顾客感觉不被尊重，信息也没收集完整等顾客说完，停顿1秒再回应
3直接问"您便秘吗？"顾客尴尬、觉得突兀，不愿回答放在饮食问题后顺带带出，用"顺便问一下"
412个问题全部照着问，一个不落时间太长，顾客疲倦，重点不突出根据主诉选6-8个重点问，其他见机行事
5顾客说了很多，顾问一直点头不追问信息量大但质量差，没有挖到核心听到关键信息立刻追问，不要等顾客说完再问
6Q12期望锁定忘了问，或者问完没记录失去成交锚点，报价时无法和顾客需求对应问诊结束前一定要问，并明显记录下来

演练A：话多型顾客——色斑+干燥，爱聊天
场景一
▼

顾客设定卡（扮演者参考）

人物：38岁，宝妈，颧骨色斑明显，皮肤干燥，生完孩子后开始变差。喜欢聊天，回答问题容易跑题（斑→聊孩子→聊老公→聊旅游）。对皮肤护理有意愿但不紧迫，防御心不强。

顾问提问 → 顾客典型回答 → 顾问应对要点
顾问Q1："今天最在意的皮肤问题是？"

顾客："就是这个斑啊，还有皮肤好干，抹了水感觉就没了。对了，我昨天带孩子去公园，晒了好久，也不知道有没有影响……（开始跑题）"

顾问应对：先回应（"晒了皮肤确实要注意"），然后总结收回："好，那主要是斑和干燥，我记下来了，等会儿重点看这两个方向。您说的斑——大概是什么时候开始明显的？"（自然带回Q2）
顾问Q2："斑什么时候开始明显的？"

顾客："生完孩子之后！我老公说我变老了好多……（聊老公）……对了我还去做过一次激光，没什么用……"

顾问应对：等顾客说一段后，用总结承接："明白了——产后、做过激光、感觉没什么效果，这些我都记下来了，很重要。做激光是什么时候？大概做了几次？"（锁定关键信息，顺带问Q11医美史）

演练评分重点

  • 是否能在不打断顾客的情况下，把话题带回皮肤主题
  • 跑题内容里有没有发现隐藏信息（如"做过激光"），并追问
  • 总时长控制在10分钟内

演练B：沉默型顾客——痘痘，回答简短
场景二
▼

顾客设定卡

人物：25岁，职场新人，下巴和两颊反复长痘两年，平时话少，回答都是"嗯/还好/差不多/就那样"。不是防御，只是性格内敛，需要顾问主导。

应对沉默型的核心技巧展示
顾问Q1："今天最在意的皮肤问题是？"

顾客："就是痘痘。"（停顿，没有展开）

顾问应对（给选项）："是一直都有，还是最近突然多了？" → 顾客："一直都有。" → 顾问："大概是从什么时候就开始了？上学的时候，还是工作之后？"（继续用二选一，帮她回忆）
顾问Q7饮食：

顾客："还好。"（沉默）

顾问应对（先说观察，再确认）："我看您脸型，感觉是容易出油的类型——一般这种情况喜欢吃辣或者甜食的概率挺高的，您是哪种？" → 让顾客在"辣"和"甜"里选，降低回答难度

演练评分重点

  • 12题问完没有出现两两相对的沉默超过3秒
  • 使用了至少5次"二选一"问法
  • 问诊结束时顾客有没有明显比开始更放松

演练C：防御型顾客——抗衰，警惕心强
场景三
▼

顾客设定卡

人物：45岁，高净值顾客，关注抗衰，有医美经历（填充/激光）。曾被其他地方"套路"过，警惕心强，经常问"你问这个干嘛""是要让我买东西吗"。需要先降低商业感，再深入问诊。

防御型核心应对策略
顾问Q11医美史：

顾客："你问我做过什么医美干嘛？是要让我买东西吗？"

顾问应对（解释铺垫）："您放心，我问这个完全是为了您的安全——有些项目和之前做过的医美是有相互影响的，我需要提前知道，避免给您推荐不合适的，帮您少花冤枉钱。当然您不想说也完全没关系，不会影响今天的服务。"
顾问Q9压力：

顾客："你们做皮肤的，问这些干嘛？"

顾问应对："哈，这个问题很多人都觉得奇怪——其实皮质醇（压力激素）升高会直接加速胶原流失，这是有医学研究支持的。我问这个是想看看您皮肤老化有没有压力方面的因素，这样我们的方案才能更针对性，而不是每个人都一样。"

演练评分重点

  • 每次被质疑都能用"解释铺垫型"化解，语气不慌、不道歉、不强词夺理
  • 问诊过程中没有明显的商业推销感
  • 结束时顾客有没有降低防御（可用"顾客角色感受如何"来互相评估）
